# Data Analytics Projects

This repository showcases data analytics projects focused on cleaning, processing, and visualizing data, building models when appropriate, and communicating results in a clear, decision-oriented way. The work includes both coursework-based projects and an independent Excel dashboard project.

### 1) Econ 104 Projects (Data Science for Economists)
The projects in this repository were completed for UCLA Econ 104 (Data Science for Economists), taught by Professor Kimberly Boswell. The course covers a variety of topics, including heteroskedasticity, serial correlation, instrumental variables, binary choice models, and regularization methods.

The three projects were completed by a team of four. My primary responsibilities included data processing and visualization, contributing to modeling, and reporting results in non-technical terms.

### 2) Interactive Dashboard (Excel)
This Excel project is an independent project completed outside of school. It uses pivot tables (and interactive filters such as slicers) to build an interactive dashboard for retail sales data.
